# EdumateAI_Project

Description: 
    Simple AI-assisted study platform with a Node.js backend and static frontend pages for learning, quizzes, and task tracking.
    
Main Folders:
    Backend, Frontend, study-assistant
        
Features:
    Backend API serving app logic and data.
    Frontend static pages: login, signup, dashboard, study assistant, tasks.
    Separate study-assistant service (additional tooling or bot).

Folder Overview:
    Backend: server code and environment config (.env).
    Frontend: HTML, CSS, and client JS for UI pages.
    study-assistant: helper service code.

Usage:
    Visit the frontend (e.g., index.html) to sign up or log in.
    Use the dashboard to access study tools and assistant features.
    Backend endpoints power authentication and data—check server.js for available routes.
